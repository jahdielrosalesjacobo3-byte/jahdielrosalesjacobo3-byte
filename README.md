## About

I am **Jahdiel Rosales**, a **Full-Stack Software Engineer, Cybersecurity Specialist, and Advanced AI Engineer** dedicated to designing and building secure, scalable, and intelligent software ecosystems across **Web, Android, iOS, Cloud, and Agentic AI**.

My engineering philosophy bridges **Object-Oriented Programming (OOP), Clean Architecture, Offensive & Defensive Cybersecurity (DevSecOps / AppSec), and state-of-the-art Artificial Intelligence (LLMs, RAG, Multi-Agent Orchestration, MCP)** to deliver end-to-end production solutions.

### Core Engineering Pillars

* **Full-Stack Web Engineering** — Modern reactive frontends (`React`, `Next.js`, `Astro`, `TypeScript`, `TailwindCSS`, `Three.js`) paired with high-concurrency backends (`Node.js`, `FastAPI`, `Django`, `Spring Boot`, `GraphQL`, `REST`).
* **Cybersecurity & Defense-in-Depth** — Application Security (SAST/DAST), penetration testing, vulnerability research, cryptographic protocols, SIEM/SOC automation, Red & Blue Team operations, and Zero-Trust architecture.
* **Advanced Artificial Intelligence** — Autonomous multi-agent systems, Retrieval-Augmented Generation (`RAG`), Model Context Protocol (`MCP`), custom tool-use orchestration, fine-tuning, and AI-driven security & workflow automation.
* **Native & Cross-Platform Mobile Development** — Native **Android** (`Kotlin`, `Java`, `Jetpack Compose`, `Android Studio`), native **iOS** (`Swift`, `SwiftUI`, `Xcode`), and cross-platform mobile ecosystems (`Flutter`, `React Native`).
* **Object-Oriented & Multi-Paradigm Mastery** — Deep command of OOP design patterns, SOLID principles, clean architecture, domain-driven design (DDD), and systems programming across a wide spectrum of languages.

### Open To

**Full-Stack Architecture • Cybersecurity & AppSec Engineering • Advanced AI & Agentic Systems • Mobile Development (Android / iOS) • Technical Leadership**
